# Ziqi Xu — Professional Website

A multi-page professional portfolio for Ziqi Xu, connecting actuarial science, statistics, data science, machine learning, and quantitative research.

## Run locally

```bash
pnpm install
pnpm dev
```

## Verify

```bash
pnpm test
pnpm build
```

The site deliberately uses a few content placeholders for education, experience, credentials, professional photograph, and LinkedIn. Replace those details in `src/content/site.ts` and `src/main.tsx` when the final information is ready.
